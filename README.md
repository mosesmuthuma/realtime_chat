# Real-Time Chat Application

A full-stack, feature-rich real-time chat application built with Node.js, Express, Socket.io, and MongoDB.

## Features
- **Real-Time Messaging:** Instant message delivery across rooms using WebSockets.
- **Dynamic Channels:** Create custom channels and manage sidebar visibility.
- **Unread Message Badges:** Background room tracking with live unread notification badges.
- **User Presence & Authentication:** Persistent username tracking via `localStorage` and live online user lists.
- **Interactive Tools:** Typing indicators and complete message history persistence via MongoDB.
